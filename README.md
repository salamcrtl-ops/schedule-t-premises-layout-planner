# Schedule T Premises Layout Planner

Offline HTML application for Unani and Ayurvedic manufacturing consultants.

## Features
- Input premises size (length × width in feet)
- Select product categories (Arq/Ark, Syrup/Sharbat, Powder/Churna/Sufoof, Pills/Habb/Qurs/Vati/Tablets, Capsules, etc.)
- Generates rough blueprint as per Schedule T of Indian Drugs & Cosmetics Rules
- Area summary with go/no-go check against 1200 sq ft base (+400 for dual system)
- Supporting areas (RM store, FG store, packing, QC, furnace if needed, etc.) auto-included
- Works fully offline on desktop and mobile
- Printable layout

## Usage
Open `index.html` in any browser. No internet required after download.

## Disclaimer
This is a rough planning aid only. Actual layouts must be approved by the State Licensing Authority. Areas based on commonly published Schedule T Part II minima. Do not use as sole basis for licence application.
